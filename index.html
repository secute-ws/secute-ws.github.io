SECUTE 2026

The 2nd Workshop on Security Testing for Complex Software Systems

2026 - Munich, Germany

Co-located with ASE 2026

Motivation

Following the first edition held in 2024, the 2nd International Workshop on Software Security Testing (SECUTE) aims to build a community where researchers and practitioners can discuss new ideas and share fresh insights on the security testing of software systems.

SECUTE places particular emphasis on proposing innovative automated techniques and methods to simplify the creation, management, and evolution of automated tests, aiming to detect security flaws in source code.

While SECUTE welcomes studies involving established testing approaches, such as vulnerability scanning and fuzzing, it also aims to attract research on code-level test cases that can augment the existing functional test suites of software projects. SECUTE also emphasizes empirical studies analyzing how security testing is performed in real-world projects and what challenges developers face when dealing with it.

Supporting Project

SECUTE has been organized in the context of the SEC4AI4SEC project.

SEC4AI4SEC is a European project aimed at developing cutting-edge technologies, open-source tools, and new methodologies for designing and certifying secure AI-enhanced systems and AI-enhanced systems for security.
