SECUTE 2027

The 3rd International Workshop on Security Testing for Complex Software Systems

2027 · San Sebastián, Spain

Co-located with ICST 2027

Paper submission deadline: 1 February 2027

About

Following the editions held in 2024 and 2026, the 3rd International Workshop on Software Security Testing (SECUTE) is a forum where academic researchers and industry practitioners can present new ideas on the security testing of software systems and discuss directions and fresh insights. SECUTE aims to build a community that believes in the value of performing dedicated testing activities specifically for security.

SECUTE appeals to the ICST community due to its strong connection to software testing and aims to increase attention to security concerns, which entail a different set of tricky challenges than other testing activities and are often underestimated or neglected.

Scope

Security testing, among other things, involves checking whether specific interactions with the target software affect security-relevant properties such as confidentiality, integrity, and availability. One common type of security test is one that reveals the presence of a security vulnerability in software, possibly localizes it in the source code, and assesses its exploitability and impact.

SECUTE emphasizes introducing innovative methods and techniques to support security testing, such as creating and managing test cases. Of particular interest, SECUTE aims to call for the presentation of novel approaches that make testing actionable during development (i.e., code-level testing) and on testing artifacts beyond source code (e.g., configuration and supply chain components). Nevertheless, SECUTE also welcomes studies on more established security testing approaches, such as vulnerability scanning, fuzzing, and static analysis.

SECUTE accepts any type of study that has a direct connection with security testing, including (but not limited to) solution-oriented studies, benchmarking studies, repository mining, case studies, empirical analyses of how security testing is performed in real-world settings, surveys with industry practitioners, controlled experiments, and literature reviews.
